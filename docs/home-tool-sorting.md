# 首页工具排序与建设中入口

## 使用方式

- “弹壳工具”标题旁点击“调整顺序”，通过右上角手柄拖动卡片，松开后即时保存；点击“完成排序”恢复普通入口。
- 鼠标和触屏使用相同的 Pointer Events 处理，只有手柄阻止触摸滚动；普通卡片区域仍可正常浏览页面。
- 手柄支持 Alt＋左右方向键移动。提供“恢复默认”；拖动取消、未移动的点击、拖到网格外不提交排序。
- 排序保存在当前浏览器的 `danke-home-tool-order:v1`，不同步到服务器或其他浏览器；存储不可用时当前页面仍能排序并给出说明。
- 旧 ID 忽略、隐藏工具继续隐藏、新增工具保留并按默认顺序追加，不更改道具或业务数据。

## 建设中卡片

- 共享蒙版文字由 14px 提高为手机 18px、较大屏幕 20px。
- 工具区的伤害计算器、活动数据，以及游戏资料中的攻略，改用无链接禁用分组，不再仅依赖视觉蒙版；没有 href 或可聚焦导航入口，保留读屏状态说明。
- 排序模式可通过卡片外独立手柄调整建设中工具的位置，但卡片本身不能跳转。
- 可用工具保留原本的站内客户端导航或外链打开方式；顶部导航和页面 URL 不做删除。

## 验证与回滚

- 5 个相关测试文件共 14 项通过（4.34 秒），类型检查及相关 ESLint 通过。
- 覆盖鼠标/触屏事件模拟、键盘移动、重挂载恢复、恢复默认、不可用存储、拖动取消/外部落点，以及建设中条目无链接。首页分类展开与滚动恢复、原导航回归通过。
- 本地首页 GET 返回 HTTP 200，包含排序控件及禁用卡片标记。
- 独立副本 `/tmp/danke-web-home-tool-sort-5mnaqaj8` 静态构建通过（244 页、67.05 秒），未覆盖当前站点构建产物。
- 浏览器控制工具仍受 WSL `sandboxCwd` 路径错误阻塞；桌面实际拖动、手机触屏、边缘滚动和视觉尺寸验收尚未完成。
- 回滚仅撤回本次首页工具与共享卡片包装变更，恢复原建设中样式及相关断言；本地排序键可忽略或移除，不涉及接口和数据库。
